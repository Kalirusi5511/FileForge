*# FileForge*



*Convert documents, source code, images and archives into plain text.*



*## Features*



*- PDF → TXT*

*- DOCX → TXT*

*- XLSX → TXT*

*- HTML → TXT*

*- JSON → TXT*

*- Images → TXT (OCR)*

*- ZIP extraction*

*- Duplicate file detection*



*## Installation*



*pip install -r requirements.txt*



*## Run*



*python app.py*
